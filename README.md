# Pedro Ferreira · Software Engineer

Código do meu portfólio, publicado em https://ferreiradrope.github.io/

Página única em HTML, CSS e JavaScript, sem framework e sem etapa de build.

## Arquivos

- `index.html`: todo o conteúdo.
- `style.css`: temas claro e escuro e layout responsivo.
- `app.js`: troca de tema, cópia do e-mail e uma consulta à API pública do GitHub que mostra, ao vivo, quantos commits do PratoFácil são meus.
- `img/`: foto e ícones.

## Rodar localmente

```bash
python -m http.server 4174 --bind 127.0.0.1
```

Depois abra http://127.0.0.1:4174/
